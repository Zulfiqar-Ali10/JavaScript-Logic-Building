# 🚀 JavaScript Mastery Logic Building Challenge

A structured and disciplined journey of practicing JavaScript logic problems daily to strengthen problem-solving ability, enhance logical thinking, and achieve mastery in core JavaScript concepts.

---

## 📘 Overview
This repository contains multiple folders (Class_01, Class_02, …), each representing a day of practice with logic-based JavaScript exercises.  
The focus is on building **strong programming logic through consistency, clarity, and gradual complexity.**

---

## 🧠 Concepts Covered
- 🔹 Variables & Data Types  
- 🔹 Conditionals & Loops  
- 🔹 Functions (Normal, Arrow, Higher-Order)  
- 🔹 Arrays & Objects  
- 🔹 String Manipulation  
- 🔹 Recursion & Mathematical Logic  
- 🔹 ES6+ Features (map, filter, reduce, destructuring)
